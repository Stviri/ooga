# Extra examples

These need something the `ooga --test` checks can't count on, so they are not checked automatically:

| File | Needs | Run it |
|---|---|---|
| `18_web.ooga` | internet | `ooga examples\extra\18_web.ooga` |
| `19_window.ooga` | Windows, and the Windows `ooga.exe` (with the .NET Desktop Runtime) | `ooga examples\extra\19_window.ooga` |

`19_window.ooga` opens a window: type your name, press **Greet**, tick **shout it**, press **Greet** again, then **Close**.
